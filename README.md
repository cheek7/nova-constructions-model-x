# NOVA Construction — Model X

Официальный веб-сайт генерального подрядчика NOVA Construction: проектирование, строительство и монтаж металлоконструкций коммерческих и промышленных зданий под ключ.

## 🚀 Стек технологий
- HTML5 (Семантическая разметка, Open Graph, SEO)
- Vanilla CSS3 (Custom Properties, Glassmorphism, Responsive Grid/Flexbox)
- Modern Vanilla JavaScript (Интерактивные калькуляторы, фильтры проектов, модальные окна, анимации)

## 📦 Развертывание (Deploy on Vercel)
Сайт оптимизирован для мгновенного развертывания на **Vercel**:
1. Импортируйте репозиторий в [Vercel](https://vercel.com).
2. Framework Preset: `Other` (Static HTML).
3. Root Directory: `./`.
4. Нажмите **Deploy**.
